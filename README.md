# Quest-Cord

Quest-Cord is a pink-themed desktop companion for browsing a game catalogue and publishing your selected title as a Discord Rich Presence activity.

## Status

Initial project setup is in progress.

## Safety and privacy

- Quest-Cord does not ask for your Discord password or token.
- It does not launch games or pretend that a game process is running.
- Discord activity is published through the official Rich Presence integration.
